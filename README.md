# 優先順位ノート(PWA)

緊急度×重要度でタスクを整理する、スマホのホーム画面に追加できるアプリです。

## ローカルで試す

```bash
npm install
npm run dev
```

表示されるURL(例: http://localhost:5173)をスマホと同じWi-Fiにいる別ブラウザで開くか、
そのままPCで確認できます。

## スマホのホーム画面に追加できるようにする(本番公開)

PWAとして「ホーム画面に追加」を使うには、httpsで配信されている必要があります。
無料で数分でできるおすすめの方法は Vercel です。

1. このフォルダをGitHubリポジトリにアップロード
2. https://vercel.com にアクセスし、GitHubでログイン
3. 「New Project」から作成したリポジトリを選択してデプロイ(設定はそのままでOK。
   Framework Preset は自動で Vite と認識されます)
4. 発行されたURL(例: https://your-app.vercel.app)をスマホのSafari/Chromeで開く
5. 共有メニュー →「ホーム画面に追加」

Claude Codeにこのフォルダを渡して
「このプロジェクトをVercelにデプロイして」
と頼めば、GitHub連携やコマンド実行まで一緒に進められます。

## データについて

タスク・メモ・履歴はすべて端末のブラウザ内(localStorage)に保存されます。
他の端末とは同期されません。ブラウザのデータを消去すると内容も消えるのでご注意ください。
